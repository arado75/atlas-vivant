# P4-02 + P5 Baseline - 2026-04-21

## Objectif

Enchainer P4-02 puis P5:
- notes/hypotheses liees a chaque snapshot
- export briefing par snapshot (Markdown + JSON)
- navigation multi-echelles et couche epistemique pilotable

## Ce qui est livre

### P4-02 annotations/hypotheses snapshot

- structure `investigation` ajoutee dans `AtlasSceneSnapshot`:
  - `whatIsKnown`
  - `fragilePoints`
  - `hypothesis`
  - `hypothesisStatus`
  - `contestationNotes`
  - `epistemicStatus`
  - `confidencePercent`
  - `version`
  - `updatedAtMs`
- action store `updateSceneSnapshotInvestigation(snapshotId, partial)`:
  - met a jour les champs
  - incremente la version
  - horodate la revision
- UI timeline:
  - edition des annotations par snapshot
  - resume hypothesis/epistemique/confiance/version

### P4-03 export briefing snapshot

- export par snapshot:
  - `Export MD`
  - `Export JSON`
- contenu briefing:
  - cadre scene (temps/couches/graphe)
  - contexte Mind
  - ce que l on sait
  - ce qui reste fragile
  - hypothese + statut + confiance
  - contestation / contre lecture

### P5-01 navigation multi-echelles

- nouveau preset global `multiScaleViewPreset`:
  - `planetary`
  - `systemic`
  - `regional`
  - `local`
- panneau `Actions rapides` active:
  - presets multi-echelles
  - ponts directs vers `Globe`, `Graphe`, `Orion`
- le globe applique le preset a la vue (rotation/zoom) selon le focus courant

### P5-02 couche epistemique continue

- nouveau filtre global `epistemicLayerFilter`:
  - `all`
  - `observation_only`
  - `hypotheses`
  - `causal_probable_plus`
- filtre applique dans:
  - graphe causal (relations affichees)
  - Atlas Mind diagnostics (file attention)
- le filtre est snapshote/restaure via scene snapshot

### P5-03 garde-fous prudentiels (base)

- Orion conserve les avertissements epistemiques et peut importer le contexte du focus actif.
- lecture plus explicite des limites directement dans le flux de proposition.
